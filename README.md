  # Todo App

The Todo App lets users create, read, update, and delete to-do tasks. A task has a description and can be either completed or active. Completed tasks can be deleted all at once. Also, the Todo App will save all changes to the API.

- [Demo](https://Vasyl-Zhyliakov.github.io/todo_app/)

# Technologies used
- React
- TypeScript
- Fetch Api
- Sass(SCSS)
- Bulma and FontAwesome
